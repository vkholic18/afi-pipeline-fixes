## Opening a ticket via IBM Cloud support portal

This option can be exercised only by the CI team members.

Instructions are [here](https://cloud.ibm.com/docs/get-support?topic=get-support-open-case&interface=ui)

By default all accounts (even if paid account) cannot open high severity tickets.
To have the default behavior changed, the account owner must open a ticket to Account Management. 
Then the RSET team  will do the needed changes. @gcar is a useful contact point in case of help needed.
