# Razee templates

- There are five templates:
  - PR to dev-integration
  - merge to dev-integration
  - PR to master
  - merge to master
  - merge to master with deploy dal

- These templates should be used for razee workspaces (Supports both either images and packages)

## Key aspects
- Has update inventory flow
- Uses build.sh for building through generic-workspace-build.sh
- Requires build-meta.yaml for the artifacts/inventory flow
