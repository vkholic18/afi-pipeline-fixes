# Credential Policies

This page outlines policies for handling credentials for the `concibm@us.ibm.com` account and access to the CI cloud VPC account and resources.

## Credential rotation

All credentials must be rotated within 365 days.  This rotation is driven by the W3 Id process.

## Credential revocation

All credentials and API keys will be rotated within 24 hours when a team member leaves the team.

## Compromised credentials

All compromised credentials must be rotated within four hours of the compromising event.
